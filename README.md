# West Village Vlog 熟語帳

NYの1日Vlog（[YouTube](https://www.youtube.com/watch?v=ADXmnbZMeO8)）から拾った英語の熟語94個を、5つのレッスンに分けてまとめた学習ページです。

**サイト:** https://dsktnd.github.io/English_idiom/

## できること

- 熟語カードの「▶ この場面」で、埋め込みの動画がその場面から再生されます
- 「区間リピート」で、その熟語の場面だけを繰り返し再生できます
- 英語・日本語での検索、レッスンごとの絞り込み
- 「意味を隠す」で暗記チェック（カードをタップすると表示）
- 「覚えた」にチェックした熟語は、ブラウザに保存されます
